# Guía del repositorio

- Este repositorio aún no está inicializado: su único archivo de proyecto rastreado es `LICENSE` (MIT).
- No asumas un lenguaje, framework, gestor de paquetes, estructura de código fuente, comando de pruebas ni flujo de despliegue hasta que el proyecto los establezca.
- Al introducir la primera implementación, añade las instrucciones de configuración y verificación correspondientes con su herramienta, en lugar de inventar comandos para este repositorio.
